# IrSL-News: A Large-Scale Iranian Sign Language Dataset

This repository provides the official benchmark implementation and experimental pipeline for the IrSL-News dataset.

The benchmark is based on the original implementation of:

> SpaMo  
> Authors:  Eui Jun Hwang et al.  
> Repository: [https://github.com/eddie-euijun-hwang/SpaMo](https://github.com/eddie-euijun-hwang/SpaMo)

This repository contains modifications and extensions made by Sahar Aghakhani to support the IrSL-News dataset.
## Dataset

The IrSL-News dataset is a dataset created and annotated by Sahar Aghakhani and collaborators at the **Social and Cognitive Robotics Laboratory, Sharif University of Technology**.

The dataset is currently under archival and review, and is **not yet publicly released**.

Access is temporarily restricted to internal collaborators.  
A formal public release, access protocol, and citation information will be provided upon paper acceptance.
